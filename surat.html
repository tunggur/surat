Integrasi Google Sheets Database

Panduan Menghubungkan Google Sheets:

  1. Buat Spreadsheet baru di Google Drive dengan tab: PENDUDUK, USERS, SURAT_KELUAR, dan TEMPLATES_SURAT.
  2. Buka Extensions > Apps Script pada Google Sheets Anda.
  3. Salin kode Google Apps Script di bawah ini dan Publish sebagai Web App (Access: Anyone).
  4. Tempelkan Web App URL hasil Deploy pada kolom di bawah.
